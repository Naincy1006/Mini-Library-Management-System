# Library Management System (Python)

A Python project implementing a simple **library management system** using Object-Oriented Programming (OOP).

---

## Features
- Display available books in the library  
- Lend books to users and track borrowers  
- Return books to the library  
- Add new books to the library  
- Handles invalid inputs gracefully  

---

## Concepts Used
- Python classes and objects  
- Dictionaries and lists  
- Loops and conditional statements  
- User input handling  

---

## How to Run
1. Clone or download the repository.  
2. Open `library_management_system.py` in any Python IDE or terminal.  
3. Run the program:  
   ```bash
   python library_management_system.py
